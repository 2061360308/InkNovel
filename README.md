color_scheme_seed：用于生成默认配色方案的种子颜色。
font_family：设置全局字体。
use_material3：是否启用 Material3 风格。
appbar_theme 等：针对不同控件（如 AppBar、Badge、Banner 等）的主题定制。
color_scheme：直接覆盖应用的配色方案。
divider_theme/divider_color：分割线的样式和颜色。
button_theme/outlined_button_theme/text_button_theme 等：各种按钮的主题。
icon_theme：图标的主题。
list_tile_theme：列表项的主题。
navigation_bar_theme/navigation_drawer_theme/navigation_rail_theme：导航相关控件的主题。
splash_color/highlight_color/hover_color/focus_color：控件交互时的颜色。
canvas_color/scaffold_bgcolor/card_bgcolor：不同界面区域的背景色。
text_theme/primary_text_theme：文本样式。
progress_indicator_theme/radio_theme/slider_theme/switch_theme：进度条、单选框、滑块、开关等控件的主题。
visual_density：控件的密集程度（如紧凑或宽松布局）。
